# 🚀 CodeOrbit To-Do List — Smart Task Manager

A modern, responsive and interactive To-Do List application developed using HTML, CSS and JavaScript as part of the CodeOrbit Frontend Development Internship.

The application helps users organize tasks, manage priorities, track progress and maintain productivity through a clean and interactive interface.

---

## 📌 Project Overview

The CodeOrbit To-Do List is a browser-based task management application that allows users to create, organize, search, edit and complete tasks.

Task information is stored using browser localStorage, allowing tasks and preferences to remain available even after refreshing the page.

---

## ✨ Features

### 📝 Task Management

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Mark completed tasks as active again
- Clear all completed tasks

### 🎯 Priority Management

Tasks can be assigned:

- 🟢 Low Priority
- 🟡 Medium Priority
- 🔴 High Priority

### 🏷️ Categories

Tasks can be organized into:

- 🏠 Personal
- 📚 Study
- 💼 Work
- 💻 Project
- 🛒 Shopping

### 📅 Due Dates

Users can assign a due date to each task.

### 🔍 Search

Search tasks instantly using the search bar.

### 🔎 Filters

Tasks can be filtered using:

- All
- Active
- Completed

### 📊 Statistics

The application displays:

- Total Tasks
- Completed Tasks
- Remaining Tasks
- Overall Progress Percentage

### 📈 Progress Bar

A dynamic progress bar shows the percentage of completed tasks.

### 🌙 Dark Mode

Users can switch between:

- Light Mode
- Dark Mode

The selected theme is saved using localStorage.

### 🔔 Toast Notifications

Interactive toast notifications are displayed for actions such as:

- Adding a task
- Updating a task
- Completing a task
- Deleting a task
- Clearing completed tasks
